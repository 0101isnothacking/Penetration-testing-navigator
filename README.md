# Penetration Testing Navigator
A simple penetration testing methodology and cheatsheet for CTFs, labs, and certification prep.

# About
This is my personal collection of notes and methodology for penetration testing. I made this to help me follow a basic process instead of randomly running tools or missing important steps.

# Methodology
1. Recon — Find domains, IPs, and other information.
2. Enumeration — Scan ports and check services.
3. Vulnerability Assessment — Look for outdated software and misconfigurations.
4. Exploitation — Get initial access.
5. Post-Exploitation — Explore the system and collect useful information.
6. Privilege Escalation — Look for ways to become root or SYSTEM.
7. Pivoting — Access other systems or networks.
8. Reporting — Document what was found and how it was done.

# How to Use
1. Clone the repository:
2. git clone https://github.com/01011isnothacking/Penetration-testing-navigator.git
3. Rename the obsidian folder to .obsidian.
4. Open the folder in Obsidian to use the notes and mind maps.

# Goal
Keep things simple, stay organized, and avoid missing important steps during testing.
