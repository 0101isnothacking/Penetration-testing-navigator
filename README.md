# Penetration-testing-navigator

A practical, step-by-step penetration testing methodology and cheatsheet built to help you during penetration testing/ctf.
Offensive Security Methodology & Playbook

This is my personal hacking methodology and notes collection. I built this playbook to help me stay organized while studying for certifications like CPTS and PNPT, as well as practicing on labs like Hack The Box. Instead of randomly running tools or blindly throwing exploits at a box, this guide gives you a clear, repeatable process to follow from start to finish.
Why I Created This

When you are working through a lab or taking an exam, it is easy to get lost or forget a basic enumeration step. This repository breaks down the entire testing process into 8 simple phases, with a heavy focus on:

Systematic Enumeration: Making sure you check every open port thoroughly before trying to exploit anything.
Saving Credentials: Keeping track of every password, hash, or key you find so you can reuse them later.
Visual Notes: Easy-to-read diagrams and cheat sheets you can look at quickly while hacking.

# The 8-Step Workflow

1. Reconnaissance: Finding IP addresses, subdomains, and domain info.
2. Enumeration: Scanning ports and checking common services (HTTP, SMB, LDAP, SSH, etc.).
3. Vulnerability Assessment: Checking software versions and finding misconfigurations.
4. Exploitation: Using your findings or credentials to get your initial shell on the target.
5. Post-Exploitation: Looking around the target system to see what files and users exist.
6. Privilege Escalation: Finding a way to move from a basic user to root or SYSTEM.
7. Pivoting: Using your access on one machine to reach hidden internal networks.
8. Reporting: Writing down what you found, how you did it, and how to fix it.
