# Penetration Testing Navigator
A simple penetration testing methodology and cheatsheet for CTFs, labs, and certification prep.

# About
This is my personal collection of notes and methodology for penetration testing. I made this to help me follow a basic process instead of randomly running tools or missing important steps.

# Methodology
Recon — Find domains, IPs, and other information.
Enumeration — Scan ports and check services.
Vulnerability Assessment — Look for outdated software and misconfigurations.
Exploitation — Get initial access.
Post-Exploitation — Explore the system and collect useful information.
Privilege Escalation — Look for ways to become root or SYSTEM.
Pivoting — Access other systems or networks.
Reporting — Document what was found and how it was done.

# How to Use
Clone the repository:
git clone https://github.com/01011isnothacking/Penetration-testing-navigator.git
Rename the obsidian folder to .obsidian.
Open the folder in Obsidian to use the notes and mind maps.

# Goal
Keep things simple, stay organized, and avoid missing important steps during testing.
